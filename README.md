# Expense Tracker

A modern Expense Tracker application built using Python and Tkinter.

## Features

* Add expenses
* Expense category selection
* Track total expenses
* Save expenses in CSV file
* Modern GUI design

## Technologies Used

* Python
* Tkinter
* CSV File Handling

## How to Run

1. Run the application:
   python main.py

## Project Workflow

User Input → Save Expense → Update Total → Store in CSV
